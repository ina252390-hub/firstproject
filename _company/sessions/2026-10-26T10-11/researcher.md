## 🎯 1. 문제 정의 (Problem Statement)
**타겟:** 국경 간 초소형 전자상거래 창업가 (Cross-border Micro-Business Owner)
**Pain Point:** 목표 시장(예: EU) 진출 시, 제품/서비스의 '데이터 처리 방식'이 해당 지역의 최신 규제(예: 개인정보보호, 환경 규제)와 충돌할 위험을 사전에 감지하고 비용 효율적으로 해결할 방법이 없음.

## 🔑 2. MVP 핵심 기능 (Minimum Viable Feature Set)
1.  **지역 규제 스캐너:** 사용자가 '타겟 국가'를 입력하면, 해당 국가의 **Top 3 핵심 규제 키워드** (예: EU: GDPR, CCPA, Digital Services Act)를 리스트업.
2.  **충돌 예측 시뮬레이터 (Core):** 사용자가 '자신의 서비스/제품 설명'을 입력하면, 시스템이 해당 키워드를 기반으로 **"잠재적 충돌 위험" (High/Medium/Low)**을 경고하고, 위험 발생 시의 '해결 가이드라인'을 제시.
3.  **위험 리포트:** 모든 검사 결과를 취합하여 간단한 '규제 위험 요약 리포트' 형태로 출력.

## 🏗️ 3. 초기 기술 아키텍처 설계 (Codari Input)
*   **데이터 소스:** 초기에는 정부 공개 API 및 규제 전문 웹스크래핑(Scraping)을 활용.
*   **핵심 모듈:** NLP(자연어 처리) 기반의 키워드 매칭 및 위험 점수화 알고리즘.
*   **기술 스택 (제안):** Python (Backend/NLP) + React/Vue (Frontend).
